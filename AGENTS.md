# Project Instructions

## Tech Stack
- Nuxt 3
- TypeScript
- Tailwind CSS
- shadcn-vue
- Lucide Icons
- Composition API only

## UI/UX Workflow
For any UI-related task:
- Use `ui-ux-pro-max` skill when available.
- Prefer reusable components.
- Follow existing design tokens.
- Keep layouts clean, compact, and practical.
- Ask for layout intent before major redesigns if unclear.

## Coding Constraints
- Do not change API contracts unless necessary.
- Preserve existing business logic.
- Keep components maintainable and type-safe.
